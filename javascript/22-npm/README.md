# NPM & Webpack

## Task

- Initialize an npm project.
- Install and configure Webpack.
- Use Webpack to bundle JavaScript files.
- Install and import the Faker package.
- Generate fake users using Faker.
- Display the user's name, email, city, and job.
- Add a button to generate 10 random users.
- Clear the previous users before generating new ones.
- Use a production build to generate the bundled JavaScript file.
