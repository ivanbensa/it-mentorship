# Movie Details

## Task

- Search for movies using the OMDb API.
- Display the search results as movie cards.
- Display the poster, title, and year for each movie.
- Open a separate details page when a movie card is clicked.
- Pass the IMDb ID of the selected movie through the URL.
- Use the IMDb ID to fetch detailed information about the selected movie.
- Display the movie title, poster, year, runtime, IMDb rating, genre, and plot.
- Add a back button to return to the previous search results.
