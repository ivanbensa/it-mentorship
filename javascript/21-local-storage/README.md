# Local Storage

## Task

- Create a simple login system using localStorage.
- Display the login form when the user is not logged in.
- Display the logged-in content when the user is logged in.
- Add logout functionality.
- Create a task manager for logged-in users.
- Save tasks to localStorage.
- Display saved tasks when the page loads.
- Display newly created tasks immediately without refreshing the page.
- Add a delete button to each task.
- Delete tasks from localStorage and update the task list immediately.
