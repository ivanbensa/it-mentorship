# Meal & Cocktail

## Task

- Fetch food categories from TheMealDB API.
- Display the categories in a select menu.
- Fetch and display meals from the selected category.
- Display the meal image and name.
- Open a popup when a meal is clicked.
- Fetch and display the recipe instructions for the selected meal.
- Fetch one random cocktail from TheCocktailDB API.
- Display the cocktail name, image, and instructions as a suggestion with the meal.
- Add a button to close the popup.
