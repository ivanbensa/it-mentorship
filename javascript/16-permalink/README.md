# Recipes Permalink

## Task

- Fetch recipes from the DummyJSON API.
- Display 9 recipes sorted alphabetically by name.
- Display the cuisine and cooking instructions for each recipe.
- Fetch all available recipe tags and display them in a select menu.
- Filter recipes when a tag is selected.
- Add a "Show recipe" link to each recipe.
- Create a permalink page for displaying a single recipe using its ID from the URL.
- Add the tags select menu to the permalink page.
- When a tag is selected on the permalink page, redirect back to the main page and display recipes for the selected tag.
