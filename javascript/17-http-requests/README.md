# HTTP Requests

## Task

- Create a registration form with first name, last name, and age.
- Generate age options from 18 to 100 using JavaScript.
- Validate that the required fields are filled in.
- Register a user using a POST request to the DummyJSON API.
- Save the ID returned by the API after registration.
- Create a Delete button after successful registration.
- Delete the registered user using a DELETE request and the saved user ID.
- Remove the Delete button after it is clicked.
- Send a login request using the DummyJSON authentication API.
