# TypeScript DOM & Validation

## Task

- Create an `Order` type with customer, location, product, price, and currency information.
- Create an `addOrder()` function.
- Validate the customer's name and location.
- Throw an error when the name or location exceeds the allowed format.
- Store multiple orders in an array.
- Create a `listOrders()` function.
- Display orders dynamically in the DOM.
- Display the customer's name, location, product, and price.
- Create a `search()` function.
- Search and filter orders by product name.
- Display only the matching orders.
