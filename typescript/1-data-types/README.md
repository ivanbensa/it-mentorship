# TypeScript Data Types

## Task

- Learn and use basic TypeScript data types.
- Use `string`, `number`, and `boolean`.
- Use function parameter and return types.
- Use `void` functions.
- Create and use tuples.
- Create custom types using `type`.
- Use union and literal types.
- Create an object type.
- Create a `LogEntry` type using a tuple.
- Create an `addOrder()` function.
- Use typed function parameters and a typed return value.
- Return an order object containing:
    - First name
    - Last name
    - City
    - Country
    - ZIP code
    - Product name
    - Amount
    - Currency
